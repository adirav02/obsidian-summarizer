# Complete quality examples

These two evidence packages use short sources authored for this repository and distributed under the repository's MIT license:

- `english-retry-policy/` - English source and English note from a minimal request with no restated formatting rules
- `hebrew-active-recall/` - Hebrew source and Hebrew note with the Hebrew study profile explicitly selected

Each directory contains the source, request, summary, and a dated evaluation against the skill rubric. Both summaries are hand-authored reference examples prepared during development. They were not captured from an independent live invocation of the skill. The automated checker was run as recorded after the files were written. No visual render in Obsidian was performed.
